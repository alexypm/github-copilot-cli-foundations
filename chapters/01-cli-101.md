Take a guided tour of the Copilot CLI interface before using it for development work.

## Goal

By the end of this chapter, you should know how to discover commands, switch modes, choose a model, inspect shortcuts, and continue an earlier session.

## Commands and Keys for This Chapter

| Command or key | Purpose |
|---|---|
| `copilot --name=cli-101-demo` | Start a named session |
| `Shift+Tab` | Open the mode selector |
| `/help` | Show available commands |
| `/model` | Open model and effort settings |
| `/share` | Show session export options |
| `/resume` | Show sessions that can be continued |
| `?` | Open the keyboard shortcut reference |
| `@` | Find a file to include in a prompt |
| `/exit` | End the session |

> **Pace note:** Follow one step at a time. Stop after each checkpoint so everyone can find the same screen.

## Live Follow-Along

### Step 1: Start a Named Session

From the workshop repository, run:

```powershell
copilot --name=cli-101-demo
```

> **Checkpoint:** Confirm that the Copilot prompt is open before continuing.

### Step 2: Explore the Three Modes

1. Press `Shift+Tab` to open the mode selector.
2. Find **Interactive**, **Plan**, and **Autopilot**.
3. Select **Plan**.
4. Run the prompt used in the video:

```text
I need to create a weekly AI report. What structure, naming, and other conventions should we follow? Let's plan this.
```

The option labels can vary by CLI version. You may see choices such as **Accept Plan**, **Build on Autopilot**, **Accept Plan and Build**, or **Exit Plan Mode**.

> **Checkpoint:** Plan mode should ask questions and produce a plan. It should not create the report during this exercise.

Press `Shift+Tab` again and locate **Autopilot**. Do not start work in this mode. Press `Esc` to return to Interactive mode.

| Mode | Best for |
|---|---|
| Interactive | Asking questions and approving actions as you work |
| Plan | Clarifying requirements and producing a plan before implementation |
| Autopilot | Letting Copilot work more independently after broad approval |

### Step 3: Discover Slash Commands

Run:

```text
/help
```

Read the command list, then press any key to close it. Find these commands if your CLI version provides them:

| Command | What it does |
|---|---|
| `/compact` | Summarizes conversation history to reduce context usage |
| `/delegate` | Sends repository work to a cloud coding agent |
| `/fleet` | Uses parallel subagents for advanced work |
| `/exit` or `/quit` | Leaves Copilot CLI |

Some versions also show commands for adding a permitted directory, selecting an agent, and viewing context or token usage.

> **Checkpoint:** Name one command you discovered through `/help`. Do not run `/delegate` or `/fleet` in this chapter.

### Step 4: Explore Models and Effort

Run:

```text
/model
```

1. Review the models available to your account.
2. Keep the current model selected unless the facilitator asks you to change it.
3. Find the effort setting if the selected model supports it.

The video shows **Low**, **Medium**, and **High** effort:

- **Low** favors speed.
- **Medium** balances speed and reasoning.
- **High** allows more thorough reasoning.

Available models and settings depend on your account and CLI version, so your list may differ from the video.

> **Checkpoint:** Confirm that you can reopen the model menu and identify the current model.

### Step 5: Explore Sharing and Resume

Run:

```text
/share
```

Review the available export options, such as Markdown or a GitHub Gist, then cancel without publishing anything.

Next run:

```text
/resume
```

Review the session list. Return to `cli-101-demo` if selecting another session would interrupt your work.

> **Checkpoint:** Confirm that named sessions are easier to recognize in the resume list.

### Step 6: Explore Keyboard Shortcuts

1. Type `?` to open the keyboard shortcut reference.
2. Close the reference and type `@`.
3. Notice that `@` opens file search. Press `Esc` without selecting a file.

> **Checkpoint:** Confirm that `?` opens shortcut help and `@` opens file search.

### Wrap Up

Run:

```text
/exit
```

You explored the CLI without opening or changing project files. Continue to [02 - Context and Conversations](02-context-conversations.md), where you will apply these features to code.
