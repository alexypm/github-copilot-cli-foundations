# 01 - First Steps

![First Copilot experience](../../01-setup-and-first-steps/assets/first-copilot-experience.png)

## What You Will Do

Try the three ways to use Copilot CLI and notice how each one feels.

## What This Chapter Covers

In this chapter, you will try review, explain, and generate prompts, then compare the three Copilot CLI modes.

## Goal

By the end of this chapter, you should know when to use interactive, plan, and programmatic mode.

## Follow Along

1. Start in interactive mode.
2. Ask for a code review.
3. Ask for an explanation of a small file.
4. Ask Copilot to generate a small piece of code.
5. Compare the three modes: interactive, plan, and programmatic.

## How To Follow Along

- Copy the prompt into your terminal.
- Read the answer before you type the next prompt.
- Try the same task in one different mode if you finish early.
- Compare the answer style across the three modes.

## Try These Prompts

```text
Review this file for bugs and quality issues: @samples/book-app-project/books.py
```

```text
Explain what this file does in simple terms: @samples/book-app-project/book_app.py
```

```text
Generate a function that validates a book title and returns a friendly error message if it is empty.
```

## Quick Mode Guide

- Interactive mode: best for back-and-forth exploration.
- Plan mode: best for thinking through a bigger task first.
- Programmatic mode: best for one-shot prompts and quick tasks.

## Your Practice Step

Choose one mode and try the same task in your own terminal.

## What Success Looks Like

You should see that the prompt style changes the kind of answer you get.
