# 03 - Development Workflows

![Five workflow overview](../../03-development-workflows/assets/five-workflows.png)

## What You Will Do

Use Copilot for everyday engineering work: review, refactor, debug, test, and Git tasks.

## What This Chapter Covers

In this chapter, you will use Copilot for review, refactor, debug, test, and Git-related tasks on the sample app.

## Goal

By the end of this chapter, you should see how Copilot can help with the main daily development tasks.

## Follow Along

1. Run one review prompt.
2. Run one refactor prompt.
3. Run one debugging prompt.
4. Run one test-generation prompt.
5. Run one Git-related prompt.

## How To Follow Along

- Pick one workflow and type the matching prompt.
- Wait for the answer before starting the next workflow.
- If your result is different, compare it with the group.
- Focus on one small change at a time.

## Try These Prompts

```text
Review @samples/book-app-project/books.py for bugs, quality issues, and missing validation.
```

```text
Refactor @samples/book-app-project/book_app.py to make the code easier to read without changing behavior.
```

```text
Help me debug this issue in @samples/book-app-project/books.py and explain the likely cause.
```

```text
Generate tests for @samples/book-app-project/books.py.
```

```text
Write a short commit message for the changes I made.
```

## Your Practice Step

Pick one workflow and try it on the sample app.

## What Success Looks Like

You should see that Copilot can help across the same project from multiple angles.

## Workshop Tip

Keep the tasks small. One prompt, one result, one discussion.
