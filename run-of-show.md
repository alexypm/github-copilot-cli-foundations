# Workshop Run of Show

Use this when you want to open with a short presentation first, then move directly into live practice with the participants.

## 10-Minute Intro

1. Welcome everyone and set the goal: one useful Copilot CLI workflow they can repeat later.
2. Explain the basic idea: Copilot CLI is an AI assistant in the terminal.
3. Show that the workshop uses one sample project throughout: `samples/book-app-project/`.
4. Tell participants the rest of the session is hands-on and they should follow each prompt live.

## 40-Minute Practice Plan

Use this pace so the full workshop stays at 50 minutes total.

## Practice Flow

### Chapter 00 - Quick Start

- Install or verify Copilot CLI.
- Sign in.
- Confirm the sample app works.
- Run one hello prompt.

### Chapter 01 - First Steps

- Show the three ways to use Copilot CLI.
- Try review, explain, and generate prompts.
- Let participants pick one mode and repeat it.

### Chapter 02 - Context and Conversations

- Show `@` file references.
- Compare single-file and multi-file context.
- Ask one follow-up question in the same session.

### Chapter 03 - Development Workflows

- Run review, refactor, debug, test, and commit prompts.
- Keep every prompt small and focused.
- Pause after each one so the group can try it.

### Chapter 04 - Agents and Custom Instructions

- Compare a generic prompt with a specialist agent.
- Show why focused helpers are useful for repeatable work.

### Chapter 05 - Skills

- Show a skill-triggered review.
- Compare the answer with and without the skill.
- Explain that skills are reusable checklists and rules.

### Chapter 06 - MCP Servers

- Show the connected servers.
- Explain that MCP adds live external context.
- Reinforce safe, intentional use.

### Chapter 07 - Putting It All Together

- Start with context.
- Ask for a plan.
- Make a small change.
- Verify the result.
- End with a short summary of the workflow.

## Simple Timing Suggestion

- 10 minutes: presentation intro
- 5 minutes: Chapter 00
- 5 minutes: Chapter 01
- 5 minutes: Chapter 02
- 8 minutes: Chapter 03
- 4 minutes: Chapter 04
- 4 minutes: Chapter 05
- 4 minutes: Chapter 06
- 5 minutes: Chapter 07

Total: 50 minutes

## Presenter Note

If the room is moving slowly, skip extra explanation and keep the pace on the live prompts. The workshop works best when participants are typing alongside you.
