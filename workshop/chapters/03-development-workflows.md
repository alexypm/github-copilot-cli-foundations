# 03 - Development Workflows

![Five workflow overview](../assets/five-workflows.png)

## What You Will Do

Use Copilot for everyday engineering work: review, refactor, debug, test, and Git tasks.

## Goal

By the end of this chapter, you should see how Copilot can help with the main daily development tasks.

## Follow Along

Use the book app sample as your practice example: `workshop/samples/book-app-project/`.

1. Run this review prompt: `Review @workshop/samples/book-app-project/books.py for bugs, quality issues, and missing validation.`
2. Run this refactor prompt: `Refactor @workshop/samples/book-app-project/book_app.py to make the code easier to read without changing behavior.`
3. Run this debugging prompt: `Help me debug this issue in @workshop/samples/book-app-project/books.py and explain the likely cause.`
4. Run this test prompt: `Generate tests for @workshop/samples/book-app-project/books.py.`
5. Run this Git prompt: `Write a short commit message for the changes I made.`

## How To Follow Along

- Pick one workflow and type the matching prompt.
- Wait for the answer before starting the next workflow.
- If your result is different, compare it with the group.
- Focus on one small change at a time.

## Your Practice Step

Pick one workflow and try it on the sample app.

## What Success Looks Like

You should see that Copilot can help across the same project from multiple angles.

## Workshop Tip

Keep the tasks small. One prompt, one result, one discussion.
